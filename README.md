# 📝 Task Tracker

A basic CLI tool for managing your tasks. Based on a back-end [roadmap.sh project](https://roadmap.sh/projects/task-tracker?fl=1).

### ⌨️ How to use

Currently in **Version 0.1** Task Tracker supports the following commands/arguments:

**List**
`tasktracker list`
Lists all your tasks, showing their ID number, title, status and when it was created.

**Add**
`tasktracker add <"yourtasktitle">`
Adds a task to you list

**Remove**
`tasktracker remove <id>`
Remove a task with a given ID.
